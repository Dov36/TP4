# TP4 - Arbres d'expression

Projet Python réalisé dans le cadre de l'UE UM4RBT11/UM4EE109. Il permet de représenter et de manipuler des arbres d'expression mathématique à l'aide de la classe `Noeud`, et de les afficher sous forme de graphes avec `networkx` et `matplotlib`.

## Prérequis

- Python 3
- pip
- virtualenv (`pip install virtualenv`)

## Installation

1. Cloner le dépôt
```sh
    git clone https://github.com/Dov36/TP4.git
    cd TP4
```

2. Créer et activer un environnement virtuel
```sh
    virtualenv env_tp4
```
    Sur Windows :
```sh
    .\env_tp4\Scripts\activate
```
    Sur Linux et Mac :
```sh
    source env_tp4/bin/activate
```

3. Installer les dépendances
```sh
    pip install -r requirements.txt
```

## Utilisation

```sh
python main.py
```
